개인정보와 광고의 경계

무료 서비스를 안전하게 쓰려면 무엇이 저장되고 무엇이 광고 요청으로 전송되지 않는지 알아야 합니다. 화면의 짧은 안내와 정책 원문을 함께 확인하세요.

1. 작업 자료는 기기 우선

제목·설명·기한·검토·설정은 현재 브라우저 저장 공간에 남습니다. 계정을 만들지 않으므로 자동 서버 동기화도 없습니다.

2. 광고를 두는 곳과 두지 않는 곳

광고는 충분한 원문이 있는 가이드에만 준비합니다. 작업 보드, 편집, 백업·복원, 공유, 개인정보·약관·지원 화면에는 수동 광고를 두지 않습니다.

3. 승인 전 상태

AdSense 게시자 연결 코드는 준비했지만 사이트 승인과 동의 관리 공개는 외부 절차입니다. 승인 전 실제 광고가 보이지 않을 수 있다는 점을 숨기지 않습니다.

4. 2분 실행 체크리스트

먼저 자료 경계의 시작 조건을 한 문장으로 적습니다. 화면에서 작업 내용과 광고 영역을 분리를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
