TRIPLE PANEL · PRACTICAL GUIDE

문제 해결과 지원 요청

오류가 나면 원인을 추측해 자료를 지우기보다 먼저 보존하세요. 백업, 재현, 상태 확인, 지원 요청의 순서를 지키면 복구 가능성이 커집니다.

1. 먼저 백업하기

저장 오류가 보이면 새 작업 입력을 잠시 멈추고 설정·데이터에서 백업 파일을 만듭니다. 파일이 실제로 내려받아졌는지 확인합니다.

2. 재현과 현황 확인

페이지를 새로 열어 같은 문제가 반복되는지 보고 개발 현황에서 알려진 문제와 최근 점검 시각을 확인합니다.

3. 공개하지 말아야 할 자료

지원 글에는 작업 내용, 공유 주소, 백업 파일, 개인정보, 인증 정보를 올리지 않습니다. 보안 문제는 비공개 신고 경로를 사용합니다.

4. 2분 실행 체크리스트

먼저 지원 요청의 시작 조건을 한 문장으로 적습니다. 화면에서 자료를 보존한 뒤 재현 절차를 적기를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
