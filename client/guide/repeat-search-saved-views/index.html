TRIPLE PANEL · PRACTICAL GUIDE

반복·검색·저장 보기 운영

목록이 길어질수록 기억력보다 규칙이 중요합니다. 반복 설정, 검색어, 저장 보기를 함께 사용하면 매일 같은 정리 비용을 줄일 수 있습니다.

1. 반복은 결과가 되풀이될 때만

매일·평일·매주·매월 중 실제 약속 주기에 맞는 것을 선택합니다. 완료 시 다음 작업 사본이 생기므로 제목과 기한을 한 번 더 확인합니다.

2. 검색은 다음 행동을 찾는 도구

제목·설명·태그를 함께 검색하고 오늘·중요·기한 지남 필터와 조합합니다. 결과 수가 0이면 검색어를 짧게 줄여 보세요.

3. 저장 보기는 반복 정리의 출발점

자주 쓰는 조건은 저장 보기로 이름 붙입니다. 저장 보기는 이 기기에만 남으며 서버 팀 필터와는 다릅니다.

4. 2분 실행 체크리스트

먼저 반복 규칙의 시작 조건을 한 문장으로 적습니다. 화면에서 다음 사본의 날짜와 제목을 확인를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
