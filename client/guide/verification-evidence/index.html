완료 근거를 남기는 검증 습관

검증은 일을 의심하는 절차가 아니라 다음 사람이 결과를 믿고 이어 가게 하는 짧은 기록입니다. 무엇을 확인했는지 한 문장으로 남겨 보세요.

1. 완료 조건을 관찰 가능한 문장으로

‘끝냄’ 대신 ‘PDF를 보내고 수신 답변 확인’처럼 외부에서 확인할 수 있는 결과를 적습니다. 숫자, 파일명, 확인 시각이 있으면 더 좋습니다.

2. 대표 입력과 예외를 확인하기

문서·기능·약속 모두 정상 사례 한 개와 실수 사례 한 개를 확인합니다. 모바일 화면과 새로고침처럼 사용자가 실제로 겪는 조건도 포함합니다.

3. 근거를 남긴 뒤 보관하기

검증 결과 입력 후 보관하면 작업 보드가 가벼워지고 기록은 남습니다. 다시 필요하면 보관함에서 검색해 복원할 수 있습니다.

4. 2분 실행 체크리스트

먼저 검증 근거의 시작 조건을 한 문장으로 적습니다. 화면에서 정상 사례와 예외 사례를 함께 확인를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
