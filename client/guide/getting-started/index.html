TRIPLE PANEL · PRACTICAL GUIDE

첫 작업을 1분 안에 시작하기

처음에는 기능을 모두 배우려 하지 않아도 됩니다. 한 줄 작업을 만들고, 실제로 시작할 때 옮기고, 끝난 뒤 근거를 남기는 세 동작만 익히면 됩니다.

1. 결과가 보이는 한 줄 쓰기

명사만 적은 ‘보고서’ 대신 ‘고객 제안서 첫 장 작성’처럼 동사와 결과를 함께 적습니다. 한 줄이 너무 크면 오늘 확인할 수 있는 첫 결과로 줄입니다.

2. 화면의 세 칸 이해하기

계획은 아직 시작하지 않은 후보, 실행은 지금 손을 대고 있는 일, 검증은 결과를 확인한 일입니다. 상태를 바꾸는 순간 실제 행동도 함께 시작하세요.

3. 첫 성공 확인

작업 추가 뒤 새로고침해도 카드가 남는지 확인합니다. 저장 알림이 보이면 첫 흐름이 끝난 것입니다. 더 자세한 방법은 계획·실행·검증 글에서 이어집니다.

4. 2분 실행 체크리스트

먼저 첫 입력의 시작 조건을 한 문장으로 적습니다. 화면에서 새로고침 뒤 카드가 남는지 확인를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
