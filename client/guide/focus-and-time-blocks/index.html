집중과 시간 블록으로 실행하기

집중은 오래 버티는 기술이 아니라 한 번에 하나의 결과를 만드는 약속입니다. 시간을 먼저 정하고 그 안에 끝낼 크기로 일을 나누면 시작이 쉬워집니다.

1. 실행 중인 일의 상한 정하기

실행 칸이 가득하면 새 일을 추가하기 전에 하나를 끝내거나 계획으로 돌립니다. 개인은 한두 개를 기본 상한으로 삼으면 맥락 전환 비용이 줄어듭니다.

2. 시간 블록을 작게 예약하기

예상 시간을 25분, 50분처럼 실제 달력에 들어갈 단위로 적습니다. 긴 작업은 첫 결과 하나로 나누고, 블록이 끝나면 결과와 막힌 이유를 남깁니다.

3. 타이머를 기록으로 바꾸기

집중 타이머를 시작한 뒤 끝내면 실제 집중 분이 작업에 누적됩니다. 시간이 다 되지 않아도 결과를 확인하고 검증으로 옮길 수 있습니다.

4. 2분 실행 체크리스트

먼저 집중 시간의 시작 조건을 한 문장으로 적습니다. 화면에서 실제 집중 분과 막힘을 기록를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
