모바일 설치와 오프라인 사용

모바일에서는 빠른 입력이 핵심입니다. 연결된 상태에서 한 번 정상적으로 연 뒤 설치하면 같은 브라우저 저장 자료를 이동 중에도 이어서 볼 수 있습니다.

1. QR로 정확한 주소 열기

공개 앱 QR은 현재 서비스 주소를 가리킵니다. 카메라에서 주소를 확인하고 피싱처럼 보이는 다른 도메인으로 이동하지 마세요.

2. 설치 전 한 번 정상 로드

인터넷 연결 상태에서 작업 추가와 새로고침을 먼저 확인합니다. 그 다음 브라우저의 홈 화면에 추가 또는 앱 설치를 사용합니다.

3. 오프라인 책임

설치 후에도 자료는 브라우저 기기 저장 공간에 남습니다. 브라우저 자료 삭제나 기기 분실에 대비해 주기적으로 JSON 백업을 만드세요.

4. 2분 실행 체크리스트

먼저 오프라인 사용의 시작 조건을 한 문장으로 적습니다. 화면에서 연결된 상태에서 백업을 먼저 만들기를 확인한 뒤에 다음 단계로 이동하세요. 결과가 보이지 않으면 같은 버튼을 여러 번 누르기보다 새로고침하고 저장 알림, 현재 필터, 보관함 상태를 차례로 확인합니다. 한 번에 하나의 조건만 바꾸면 무엇이 해결했는지도 남길 수 있습니다.

5. 막혔을 때 되돌아오는 순서

문제가 생기면 새 자료를 계속 입력하기 전에 현재 상태를 백업합니다. 그 다음 마지막으로 정상이라고 확인한 화면과 지금 화면을 비교하고, 입력·필터·기기 연결 중 하나만 원인 후보로 좁힙니다. 그래도 해결되지 않으면 문제 시각, 재현 단계, 기대한 결과와 실제 결과만 지원 요청에 적습니다. 작업 내용이나 인증 정보가 들어간 원본 파일은 공개하지 않습니다. 해결한 뒤에는 같은 문제가 다시 생기지 않도록 확인한 방법을 짧게 기록합니다.
