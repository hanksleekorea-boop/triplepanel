TRIPLE PANEL · PRACTICAL GUIDE

30분 주간 검토 실전 안내

주간 검토는 지난주를 평가해 자책하는 시간이 아닙니다. 흩어진 약속을 회수하고, 끝난 결과에서 배운 점을 찾고, 다음 주의 한 가지 초점을 정하는 운영 시간입니다. 매주 같은 순서로 진행하면 머릿속 부담이 줄고 계획의 정확도가 높아집니다.

1. 5분: 들어온 일을 한곳에 모읍니다

메모, 문자, 전자우편, 회의 기록, 종이에 적은 약속을 훑어 아직 처리하지 않은 일만 계획에 옮깁니다. 모든 내용을 복사하지 말고 내가 실제로 해야 할 행동과 결과만 적습니다. 날짜가 정해진 약속은 기한을 붙이고, 다른 사람이 해야 할 일은 담당자를 구분합니다.

이 단계에서 바로 일을 시작하지 않습니다. 수집과 실행을 섞으면 한두 가지 긴급한 일에 빠져 전체 약속을 놓치기 쉽습니다. 먼저 빠짐없이 모은 뒤 다음 단계에서 선택합니다.

2. 7분: 검증된 결과를 읽습니다

지난 일주일 동안 검증으로 옮긴 작업을 봅니다. 완료 개수보다 어떤 결과가 실제 변화를 만들었는지 찾으세요. 고객 답변, 오류 감소, 의사결정 완료, 가족과의 약속처럼 가치가 생긴 순간을 짧게 적습니다.

예상 시간과 실제 집중 시간이 크게 달랐다면 이유를 한 문장으로 남깁니다. 요구가 바뀌었는지, 필요한 자료를 늦게 찾았는지, 처음부터 작업이 너무 컸는지를 구분하면 다음 계획의 크기를 더 정확하게 잡을 수 있습니다.

3. 7분: 막힘을 결정으로 바꿉니다

실행 칸에 오래 머문 일과 기한이 지난 일을 봅니다. 막힘은 상태가 아니라 아직 내리지 않은 결정인 경우가 많습니다. 자료가 필요하면 누구에게 언제 요청할지 정하고, 범위가 크면 가장 작은 결과로 나누고, 가치가 낮다면 삭제하거나 보관합니다.

같은 막힘이 두 주 연속 반복되면 더 노력하겠다는 계획만 세우지 마세요. 권한, 예산, 기술, 일정 중 무엇이 부족한지 이름을 붙이고 그 조건을 해결하는 별도 작업을 만듭니다.

4. 6분: 다음 주 한 가지 초점을 고릅니다

다음 주에 여러 결과를 만들더라도 중심이 되는 한 가지를 정합니다. “매출 올리기”보다 “유료 전환 안내 화면 공개”, “건강 챙기기”보다 “월·수·금 저녁 20분 걷기”처럼 관찰 가능한 문장으로 씁니다.

초점과 직접 관련 없는 일은 중요하더라도 순서를 뒤로 미룰 수 있습니다. 오늘 선택 기능에는 다음 영업일에 시작할 세 개 이하만 둡니다. 계획을 꽉 채우지 말고 예상하지 못한 요청을 위한 여백을 남깁니다.

5. 5분: 자료를 안전하게 마칩니다

검토 기록을 저장한 뒤 중요한 작업은 JSON 백업으로 내보냅니다. 백업 파일 이름에 날짜가 들어가므로 주별 폴더에 보관하면 복원 시점을 고르기 쉽습니다. 다른 기기로 옮길 때는 바로 교체하지 말고 먼저 파일을 검사하고 추가·변경·건너뜀 수량을 확인하세요.

검토가 끝났다면 보관함으로 옮길 완료 작업을 정리합니다. 휴지통은 자동으로 비우지 않으므로 실수로 지운 일을 복원할 수 있지만, 민감한 자료는 백업을 확인한 뒤 직접 영구 삭제합니다.
